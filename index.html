Data Cleaner for CSV/Excel

One command turns a messy export into clean data. Pro removes duplicates, trims spaces, fixes name casing, standardizes dates to YYYY-MM-DD, and converts currency text such as $1,250.00, € 89,90, or (45.00) into numbers. You also get a blanks report per column, a list of removed duplicates, and a log of values it could not parse, so nothing changes silently.

Portfolio proof

Two demos with synthetic data only. No client files. They show the same cleanup ideas as the Data Cleaner. Downloading them from this repository is not a purchase.

1. Messy CSV to a clean workbook

Before. A 65-row sales CSV: 5 duplicates, inconsistent names, case, and spaces, 3 date formats, “$” and “USD” mixed into amounts, and blank quantities.
After. A workbook with normalized, sorted data, a styled frozen header and filter, a line_total formula, SUM / AVERAGE / SUMIF figures, a customer × region pivot, and a change log (65 in, 5 duplicates removed, 60 out; 14 blank quantities set to 1 and flagged). Total revenue in the sample: 57,590.74.

Files: messy_sales.csv · clean_sales.xlsx · clean.py · make_messy.py

2. Merge CSV exports with different headers

Before. Three store CSV exports with different headers (SKU / sku / Item SKU; Units / units sold / Qty).
After. merge_reports.py input merged.xlsx writes one workbook with All_Rows (including source_file) and Summary_by_SKU. Checked result: 3 files, 45 rows. A PDF preview is included.

Files: store_a · store_b · store_c · merge_reports.py · merged.xlsx · merged.pdf
